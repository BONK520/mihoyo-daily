# 米哈游每日清单

原神 / 崩坏：星穹铁道 / 绝区零 的每日、每周任务清单和体力计算网页。

纯静态网页（HTML / CSS / JS），不需要编译，手机优先、深色模式。

## 功能

- **三款游戏分页**：原神、崩坏：星穹铁道、绝区零，底部分页切换。
- **每日 / 每周清单**：预设常见项目（每日委托、每日实训、活跃度、周本等）。
  - 点一下勾选；需要多次的项目（例如每日委托 ×4、周本 ×3）每点一下 +1，旁边的「−」可以减回去。
  - 按「编辑」可以新增、改名、删除项目，调整次数和顺序。
- **自动重置**（亚服 UTC+8）：
  - 每天 04:00 清空每日勾选；
  - 每周一 04:00 清空每周勾选。
- **体力计算器**：输入目前的原粹树脂 / 开拓力 / 电量，显示几点几分回满、还要多久；「刚刚花掉」按钮可以快速扣除。
  - 预设：原神 200 上限、8 分钟 1 点；星铁 300 上限、6 分钟 1 点；绝区零 240 上限、6 分钟 1 点。
  - 上限和回复速度可以在「设置」里修改。
- **首页**：三款游戏今天完成几项、每周进度、体力回满时间，以及下次每日 / 每周重置倒计时。
- **资料存在 localStorage**：重新整理不会消失（只保存在这个浏览器，不会上传）。

## 文件

| 文件 | 说明 |

| `index.html` | 入口页面 |

## 本地预览

直接用浏览器打开 `index.html` 即可；或在这个目录执行：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 用 GitHub Pages 发布

1. 到 repo 的 **Settings → Pages**。
2. **Source** 选 **Deploy from a branch**，Branch 选 `main`，资料夹选 `/ (root)`，按 Save。
3. 等一两分钟，网址会是 `https://<你的帐号>.github.io/mihoyo-daily/`。

## 修改预设内容

预设清单和体力数值在 `app.js` 最上面的 `GAMES` 和 `DEFAULT_LISTS`。修改预设清单不会影响已经存在浏览器里的清单；想套用新的预设，可以在网页「设置」里按「恢复预设清单」。
